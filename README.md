# 🎨 Тату-салон: чат-боты для Telegram и MAX

Полноценные чат-боты для тату-мастера с системой онлайн-записи, портфолио, отзывами
и управлением клиентами. **Две платформы** из одной кодовой базы: Telegram и MAX (VK).

## ✨ Возможности

### Для клиентов:
- 🎨 **Портфолио работ** — просмотр работ мастера
- 📅 **Онлайн запись** — удобная система бронирования с календарём
- 💰 **Прайс-лист** — информация об услугах и ценах
- ⭐ **Отзывы** — рейтинг и отзывы клиентов
- 👤 **Личные записи** — просмотр и **отмена** своих записей
- ℹ️ **О мастере** — контактная информация

### Для мастера:
- 🔧 **Админ-панель** — управление всеми записями
- 📋 **Просмотр заявок** — подтверждение / завершение / отмена / сообщение клиенту
- 💾 **База данных** — сохранение всей информации
- 🚫 **Блокировка слотов** — ручное закрытие дат/времени
- 🔔 **Напоминания** — автоматические уведомления клиентам + утренняя сводка админу

## 🛠️ Технологии

- **Python 3.10+**
- **pyTelegramBotAPI** (`telebot`) — работа с Telegram Bot API
- **requests** — HTTP-клиент для MAX Bot API
- **sqlite3** — встроенная база данных
- **python-dotenv** — управление переменными окружения

## 🚀 Установка и запуск

### 1. Зависимости
```bash
cd C:\Projects\tattoo_bot
pip install -r requirements.txt
```

### 2. Конфигурация
Скопируйте `.env.example` → `.env` и заполните:

```bash
copy .env.example .env
```

```env
# Telegram
BOT_TOKEN=ваш_токен_бота
ADMIN_ID=ваш_telegram_id

# MAX (мессенджер VK) — опционально
MAX_TOKEN=ваш_max_токен
MAX_ADMIN_ID=ваш_max_id
```

### 3. Получение токенов

**Telegram:**
1. Найдите [@BotFather](https://t.me/BotFather)
2. Команда `/newbot` → следуйте инструкциям
3. Свой ID узнайте у [@userinfobot](https://t.me/userinfobot)

**MAX (VK мессенджер):**
1. Платформа [business.max.ru](https://business.max.ru) → Чат-боты
2. Расширенные настройки → создайте бота
3. Скопируйте токен и ID

### 4. Запуск

**Только Telegram:**
```bash
python main.py
```

**Только MAX:**
```bash
python max_main.py
```

Оба бота независимы и **делят одну базу данных** (`tattoo_bot.db`). Можно запускать
одновременно в разных терминалах — клиенты TG и MAX видят общий портфолио, общий
прайс-лист и общую админ-панель мастера.

## 📱 Использование

### Для клиента
1. Нажмите `/start` (или «старт» текстом)
2. Выберите раздел в меню
3. Для записи: услуга → описание → дата → время → подтверждение
4. Активную запись можно отменить из раздела «👤 Мои записи»

### Для мастера
1. Кнопка «🔧 Админ-панель» (видна только админам)
2. Управляйте записями: подтверждение, завершение, отмена, сообщение клиенту
3. Блокируйте слоты календаря вручную
4. Получайте утреннюю сводку записей на день (8:00–12:00)

```
├── config.py            # Загрузка .env (TG + MAX)

├── .env.example
└── tests/
    └── test_database.py # 25 тестов БД
```

## 🔧 Кастомизация

### Добавление услуг / работ портфолио
Редактируйте `add_sample_data()` в `database.py`.

### Информация о мастере
Редактируйте секцию «О мастере» в `handlers.py` / `max_handlers.py`.

### ASCII-арт оверлея
Положите рядом файл `ascii-art.txt` или `art.txt` — он заменит встроенный арт.

## 📞 Поддержка

- Проверьте логи: `bot.log` (Telegram), `max_bot.log` (MAX)
- Убедитесь, что токены в `.env` корректны
- Проверьте подключение к интернету
