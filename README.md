# 🎨 Telegram Бот для Тату-салона

## 📋 Описание

Полноценный Telegram бот для тату-мастера с системой онлайн-записи, портфолио и управления клиентами.

## ✨ Возможности

### Для клиентов:
- 🎨 **Портфолио работ** - просмотр работ мастера
- 📅 **Онлайн запись** - удобная система бронирования
- 💰 **Прайс-лист** - информация об услугах и ценах
- 👤 **Личный кабинет** - управление своими записями
- ℹ️ **О мастере** - контактная информация

### Для мастера:
- 🔧 **Админ-панель** - управление всеми записями
- 📋 **Просмотр заявок** - отслеживание клиентов
- 💾 **База данных** - сохранение всей информации

## 🚀 Установка и запуск

### 1. Клонирование проекта
```bash
cd C:\Projects\tattoo_bot
```

### 2. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 3. Создание файла .env
Скопируйте файл `.env.example` и переименуйте его в `.env`:

```bash
copy .env.example .env
```

### 4. Получение токена бота

1. Откройте Telegram и найдите [@BotFather](https://t.me/BotFather)
2. Отправьте команду `/newbot`
3. Следуйте инструкциям:
   - Введите имя бота (например: Imperium Tattoo Bot)
   - Введите username бота (например: imperium_tattoo_bot)
4. Сохраните полученный токен

### 5. Получение ID для админ-панели

1. Откройте Telegram и найдите [@userinfobot](https://t.me/userinfobot)
2. Отправьте любое сообщение
3. Сохраните свой ID

### 6. Настройка .env файла

Откройте файл `.env` и заполните его:

```env
BOT_TOKEN=ваш_токен_бота
ADMIN_ID=ваш_telegram_id
```

### 7. Запуск бота

```bash
python main.py
```

## 📱 Использование бота

### Для клиента:
1. Нажмите `/start` для начала
2. Выберите интересующий раздел в меню
3. Следуйте инструкциям для записи

### Для мастера:
1. Нажмите кнопку "🔧 Админ-панель" (только для админа)
2. Просматривайте все записи клиентов
3. Управляйте статусами записей

## 💡 Примеры работы

### Запись на татуировку:
1. Клиент выбирает "📅 Записаться"
2. Выбирает услугу из списка
3. Описывает идею
4. Указывает дату и время
5. Подтверждает запись

### Управление записями:
- Клиент может просматривать свои записи
- Мастер видит все записи в админ-панели
- Статусы: pending (ожидание), confirmed (подтверждено), cancelled (отменено), completed (завершено)

## 🔧 Кастомизация

### Добавление услуг:
Редактируйте функцию `add_sample_data()` в `database.py`:

```python
services = [
    ("Название услуги", "Описание", мин_цена, макс_цена, время_в_минутах),
    # Добавьте больше услуг
]
```

Редактируйте функцию `add_sample_data()` в `database.py`:

```python
portfolio = [
```

```python
text = """
```
